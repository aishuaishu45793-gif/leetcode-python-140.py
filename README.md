# 🐍 LeetCode Python Practice (136–140)

## 📌 About the Project

This repository contains five beginner-friendly Python programming problems designed to improve programming logic and problem-solving skills. These exercises cover strings, loops, conditional statements, mathematical operations, and lists.

Each program is written in Python and can be executed using Visual Studio Code (VS Code) or a Python terminal.

## 🎯 Objectives

* Practice Python programming fundamentals.
* Improve logical thinking and problem-solving skills.
* Understand loops and conditional statements.
* Learn string manipulation and list operations.
* Practice mathematical calculations.
* Build a foundation for solving LeetCode problems.

## 📝 Program Details

### 136. Count Vowels in a String

**Objective:** Count the number of vowels in a string.

**Concepts Used:**

* Strings
* `for` loops
* `if` conditions
* Counters
* Character membership using `in`

**Example Output:**

```text
Enter a string: Hello World
Number of vowels: 3
```

### 137. Check Number Palindrome

**Objective:** Check whether a non-negative integer reads the same forward and backward.

**Concepts Used:**

* String manipulation
* Input handling
* Conditional statements
* String slicing

**Example Output:**

```text
Enter an integer: 121
The number is a palindrome.
```

### 138. Factorial of a Number

**Objective:** Calculate the factorial of a non-negative integer.

The factorial of a number is the product of all positive integers from 1 to that number. The factorial of 0 is 1.

**Concepts Used:**

* Mathematical operations
* `for` loops
* Variables
* Conditional statements
* Exception handling

**Example Output:**

```text
Enter a non-negative integer: 5
Factorial: 120
```

### 139. Find Largest and Smallest Numbers

**Objective:** Find the largest and smallest numbers in a list entered by the user.

**Concepts Used:**

* Lists
* User input
* `max()` and `min()`
* Conditional statements
* Exception handling

**Example Output:**

```text
Enter numbers separated by spaces: 10 25 5 40 15
Largest number: 40
Smallest number: 5
```

### 140. Remove Duplicate Elements

**Objective:** Remove duplicate numbers from a list while preserving the original order.

**Concepts Used:**

* Lists
* Duplicate removal
* `dict.fromkeys()`
* User input
* Exception handling

**Example Output:**

```text
Enter numbers separated by spaces: 1 2 2 3 4 4 5
Original list: [1, 2, 2, 3, 4, 4, 5]
List without duplicates: [1, 2, 3, 4, 5]
```

## ⚙️ How to Run the Programs

1. Install Python 3 on your computer.
2. Open the project folder in Visual Studio Code.
3. Create or open the required Python file.
4. Copy the corresponding program into the file.
5. Open the VS Code terminal.
6. Run the program using:

```bash
python 136.py
```

Replace `136.py` with the filename of the program you want to execute, such as `137.py`, `138.py`, `139.py`, or `140.py`.
